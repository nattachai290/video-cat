# Pumpkin & Pip: Prank War · สงครามแกล้งกัน — Storyboard v1

**YouTube Shorts** แนวตั้ง 1080×1920 · **45 วินาที** · วนลูปได้ · ตอนที่ 8 · แนว **ตลก แกล้งกันไปมา** (จังหวะเร็วแบบตอน 7: มุกทุก 3–4 วินาที)

**เรื่องย่อ.** Pumpkin กินข้าวเพลิน แตงกวาลูกหนึ่งค่อย ๆ เลื่อนมาวางข้างหลัง เขาหันไปเห็น ขนพองฟู พุ่งจรวดขึ้นไปเกาะเพดาน
Pip กลิ้งหัวเราะ "Gotcha!" → Pumpkin แก้แค้น เอาแตงกวาไปวางข้างหลัง Pip บ้าง แต่ Pip เป็นหนู ไม่กลัวแตงกวา
กัดกร้วม "Mm. Crunchy." → Pip แกล้งต่อ วางเบาะผายลมบนอาร์มแชร์ Pumpkin นั่งลง *ปู้ด* หน้าแดง "…That wasn't me." →
Pumpkin แอบไปขดตัวในโหลแครกเกอร์ยักษ์ Pip เปิดฝา เจอหน้าแมวโผล่ "BOO!" Pip พุ่งจรวดขึ้นเพดานบ้าง Pumpkin: "Gotcha!" →
**ศึกใหญ่:** ทั้งคู่ย่องคนละฝั่งของอาร์มแชร์ ถือของแกล้งคนละชิ้น ไปโผล่หลังกันพร้อมกัน หันมาเจอหน้ากันจมูกชนจมูก
กรี๊ดพร้อมกัน พุ่งขึ้นไปเกาะเพดานข้างกัน → ห้อยอยู่ด้วยกัน "…Truce?" "Truce." จับมือกัน ซึ่งแปลว่าปล่อยเพดาน ร่วงลงมาทับกันเป็นกอง →
สงบแล้ว Pumpkin กลับไปกินข้าว Pip นั่งบนหัว → หุ่นยนต์ดูดฝุ่นแล่นผ่านข้างหลัง มีแตงกวาวางอยู่บนหลัง… ตัดกลับไปที่ Pumpkin กำลังกินข้าว = เฟรมแรก วนลูป

**มุก 3 จังหวะ:** แตงกวา (แมวกลัว หนูไม่กลัว) → แกล้งกันไปมาแรงขึ้นเรื่อย ๆ (เบาะผายลม, BOO ในโหล) → แกล้งพร้อมกันจนกลัวกันเองทั้งคู่ แล้วสงบศึกจนร่วง

**ฮุก 2 วินาทีแรก:** ภาพใกล้ Pumpkin กินข้าวฟินสุด ๆ แตงกวาสีเขียวเลื่อนเข้ามาด้านหลังอย่างช้า ๆ พร้อมเสียงไวโอลินสยองปลอม ๆ (อ่านออกโดยไม่ต้องเปิดเสียง)

## การจัดฉากใน 2D

- **ห้องนั่งเล่นเดิม** มองหน้าตรง: หน้าต่างซ้าย อาร์มแชร์ขวา พรมกลาง ชามข้าวแมววางบนพรม (x≈560)
- **เพดาน** = ขอบบนของกำแพงในฉาก กล้องเงยตามตอนพุ่งขึ้น ตัวละครเกาะเพดานด้วยกรงเล็บ หันหน้าเข้ากล้อง
- **โหลแครกเกอร์ยักษ์** วางข้างอาร์มแชร์ วาดแบบภาชนะ: ขอบหลัง → ตัวละครข้างใน → ตัวโหลใส (เห็นเงา Pumpkin ขดอยู่)
- ศึกใหญ่: อาร์มแชร์อยู่กลางภาพ Pip ย่องจากซ้าย Pumpkin ย่องจากขวา อ้อมหลังเก้าอี้ แล้วโผล่ข้างหน้าพร้อมกัน
- มุมข้างใช้ตามกฎใหม่ (หนวดชี้หลัง ไม่มีแขนห้อย ขาหนูสีเทา)

## เสียง

- **เสียงพูด:** 6 ประโยค (Pip 3, Pumpkin 3) สั้นทั้งหมด
- **เอฟเฟกต์:** กินข้าว *ง่ำ ๆ*, ไวโอลินสยองปลอม, ขนพอง *ฟู่ว*, จรวดพุ่ง *ฟิ้ว*, เล็บจิกเพดาน, หัวเราะ, แตงกวา *กร้วม*, เบาะผายลม *ปู้ดดด*, ฝาโหล *ป๊อก*, BOO, เดินย่อง, กรี๊ดคู่, ร่วง *ตุ้บ*, หุ่นยนต์ *วี้*
