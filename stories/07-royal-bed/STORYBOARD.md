# Pumpkin & Pip: The Royal Bed · เตียงหลวง vs กล่องกระดาษ — Storyboard v1

**YouTube Shorts** แนวตั้ง 1080×1920 · **50 วินาที** · วนลูปได้ · ตอนที่ 5 · แนว **ตลก** (มุกที่คนเลี้ยงแมวอินทุกคน: ซื้อของแพงให้ แมวเอาแต่กล่อง)

**เรื่องย่อ.** กล่องพัสดุใบใหญ่กลางห้องนั่งเล่นกระดุกกระดิก Pip โผล่หัวออกมา "Special delivery!"
แล้วลากเตียงแมวหรูหราสีม่วงขอบทอง มีหมอนรูปมงกุฎ ออกมาจากกล่อง "A royal bed. Only the best for you."
Pumpkin เดินมาดม เหยียบเตียงหนึ่งที… แล้วหันไปจ้อง **กล่องเปล่า** ตาเป็นประกาย "…Box." กระโดดลงกล่องพอดีเป๊ะ "Perfect."
Pip ฉุน "That bed cost forty crackers!" ดึงหาง Pumpkin หลุดจากกล่อง *ป๊อก* (ล้อตอนแรก) ปิดฝากล่องแล้วนั่งเฝ้า Pumpkin ไม่ยอมแพ้ ไปยัดตัวลงกล่องแครกเกอร์ใบจิ๋วของ Pip
(ล้นทะลักทุกด้านแบบตอนติดประตูแมว) "Still… perfect."
Pip ยอมแพ้ ล้มตัวลงนอนในเตียงหลวงเอง ตัวจิ๋วจมหายไปในเบาะ "…Oh no. It IS nice."
Pumpkin มองตาขวาง อิจฉา! กระโจนเข้าเตียงบ้าง Pip กระเด็นปลิวข้ามห้อง ไปตกลงกล่องใบใหญ่ ฝาพับปิด กล่องกระดุกกระดิก = เฟรมแรก

**มุก 3 จังหวะ:** ของขวัญแพง vs กล่องเปล่า → ยัดตัวลงกล่องจิ๋ว (ล้นทะลัก) → Pip ได้นอนเตียงเอง แล้ว Pumpkin อิจฉาแย่งคืน จน Pip กระเด็นลงกล่อง (วนลูป)

**ฮุก 2 วินาทีแรก:** กล่องกระดาษใบใหญ่กลางพรมกระดุกกระดิกเอง มีเครื่องหมาย "?" ลอย แล้วหัวหนูโผล่จากฝากล่อง (อ่านออกโดยไม่ต้องเปิดเสียง)

## การจัดฉากใน 2D

- **ห้องนั่งเล่นเดิมของซีรีส์** (ตอน 2 และ 4) มองหน้าตรง: หน้าต่างซ้าย อาร์มแชร์ขวา พรมฟ้ากลางห้อง
- **กล่องใหญ่** วางกลางพรม (x≈560) เห็นจากด้านหน้าเฉียงบน ฝาพับสี่แผ่น เปิด/ปิดได้
- **เตียงหลวง** วางทางซ้ายของกล่อง (x≈260) เป็นเบาะกลมสีม่วงขอบทอง หมอนมงกุฎ
- **กล่องแครกเกอร์จิ๋ว** อยู่ข้างอาร์มแชร์ (x≈820)
- เฟรมแรกและเฟรมสุดท้าย: กล้องจับเฉพาะกล่องใหญ่ (เตียงอยู่นอกเฟรม) จึงต่อกันเนียน

## เสียง

- **เสียงพูด:** 7 ประโยค (Pip 4, Pumpkin 3)
- **เอฟเฟกต์:** กล่องกระดุกกระดิก (กระดาษแข็ง), ฝาเด้งเปิด, ลากเตียง, *วิ้ง* ความหรู, ดม *ฟุดฟิด*, กระโดดลงกล่อง *ตุ้บ*, กระทืบเท้าหนู, กล่องพับแบน *ครืด*, ยัดตัวลงกล่องจิ๋ว (เสียงบีบ *อึ้ด อึ้ด*), จมลงเบาะ *ฟุ้บ*, กระโจน *ปุ้ง*, หนูปลิว *หวือ* + *ตุ้บ*, ฝากล่องปิด
- **ดนตรี:** เพลงพิธีการหรู ๆ แบบล้อเลียน (แตรปลอม) ตอนเปิดตัวเตียง → เงียบตอนแมวหันไปมองกล่อง → เพลงซุกซน → เพลงกล่อมตอน Pip นอน → ตลกตอนแย่งเตียง
