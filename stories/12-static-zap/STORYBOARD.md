# Pumpkin & Pip: Static Zap · ไฟฟ้าสถิต — Storyboard v1

**YouTube Shorts** แนวตั้ง 1080×1920 · **45 วินาที** · วนลูปได้ · ตอนที่ 10 · แนว **ตลกแอ็กชัน มุกรัว**

**กติกาจังหวะ:** มุกใหม่ทุก 3–4 วินาที, ไม่มีช็อตเดินเข้าฉาก, มุกแรงขึ้นเรื่อย ๆ, ตัดตามแอ็กชัน, จอสั่นทุกครั้งที่ช็อต, เพลง 138 bpm

**เรื่องย่อ.** Pip เอาลูกโป่งมาถูหัว Pumpkin ที่กำลังหลับ *เอี๊ยด ๆ* ขนส้มลุกชันทีละเส้นจนตัวพองเป็นลูกบอลขนฟู →
Pumpkin ตื่น งง แตะลูกบิดประตู *เปรี๊ยะ!* ประกายไฟฟ้า ขนชี้ตั้ง หนวดหยิก → ของในห้องเริ่มลอยมาติดตัว: ถุงเท้า แครกเกอร์ รีโมต
*แปะ แปะ แปะ* แมวสะบัดตัว ยิ่งสะบัดยิ่งติดเพิ่ม: เบาะ หมอน ลูกไหมพรม Pip ก็ลอยมาติดพุง "Help!" →
แมวกลายเป็นก้อนของรวมมิตรกลมใหญ่ กลิ้งไปทั่วห้อง "I am… the junk ball." → ลูกโป่งลอยผ่านหน้า แมวตาวาว
ยกเล็บ *จิ้ม* → **ตูม!** ลูกโป่งแตก ไฟฟ้าปล่อยออกหมด ของทั้งหมดปลิวกระจาย ขนแมวแฟบลงเรียบแปล้ (เงียบหนึ่งจังหวะ) →
Pip ตกลงมา **กลายเป็นตัวฟูแทน** เป็นปอยขนกลม ๆ หูกับหางโผล่ "…Oh no." Pumpkin ยิ้มเจ้าเล่ห์ ยื่นนิ้วไปแตะจมูก Pip *เปรี๊ยะ!*
→ ตัดไปที่ Pip ล้วงถุงลูกโป่งใบใหม่ออกมา ถูหัวแมวที่หลับอยู่ = เฟรมแรก วนลูป

**มุก 3 จังหวะ:** ช็อตแรก (ขนพอง + ลูกบิดช็อต) → ของติดตัวจนเป็นลูกบอลขยะ → ลูกโป่งแตก ไฟสถิตย้ายไปอยู่ที่ Pip

**ฮุก 2 วินาทีแรก:** CU ลูกโป่งแดงถูบนขนส้ม ขนลุกชันเป็นหนาม ๆ แล้ว *เปรี๊ยะ* ประกายสีฟ้า (อ่านออกโดยไม่ต้องเปิดเสียง)

## การจัดฉากใน 2D

- **ห้องนั่งเล่นเดิม** (จากตอน 4/7) มองหน้าตรง: หน้าต่างซ้าย อาร์มแชร์ขวา พรมกลาง **ประตูกับลูกบิดทองเหลืองที่ผนังซ้าย**
- Pumpkin เริ่มหลับบนพรมกลางห้อง ทุกอย่างเคลื่อนซ้าย ↔ ขวาบนพื้น ไม่มีความลึก
- ตัวฟู: ใช้สถานะ `puff` ของ rig + วาดขนแหลมรอบตัวเพิ่ม (ต้องเช็ก 3 มุมมองว่าขนตามตัว)
- ของติดตัว: วาดเป็นชั้น ๆ รอบตัวแมว แต่ละชิ้นติดที่จุดคงที่บนตัว (หมุนตามตัวเวลากลิ้ง) หน้าแมวต้องโผล่ตรงกลางเสมอ
- ไฟฟ้า: เส้นฟ้าหยัก ๆ สั้น ๆ + แฟลชขาวเฟรมเดียว (ไม่กะพริบรัวเกิน 3 ครั้งต่อวินาที)

## เสียง

- **เสียงพูด:** 5 ประโยค (Pip 3, Pumpkin 2) สั้นทั้งหมด
- **เอฟเฟกต์:** ลูกโป่งถู *เอี๊ยด*, ขนพอง *พรึ่บ*, ไฟฟ้า *เปรี๊ยะ* (zap ใหม่ใน synth), ของแปะ *แปะ* (pop/tap), สะบัด *วืด*, กลิ้ง *ตึง ๆ*,
  ชนเก้าอี้ *โครม*, ลูกโป่งแตก *ตูม*, ของปลิว *วู้ช*, ตก *ปุ๊*
- **ดนตรี:** 26 ห้องที่ 138.67 bpm = 45 วินาทีพอดี เพลงเร็วแบบการ์ตูน หยุดเงียบตอนยกเล็บ (ช็อต 07) จนถึงหลังเสียงตูม แล้วกลับมาตอน Pip ฟู
