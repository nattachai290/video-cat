# Pumpkin & Pip: The Robot Vacuum · หุ่นยนต์ดูดฝุ่น — Storyboard v1

**YouTube Shorts** แนวตั้ง 1080×1920 · **50 วินาที** · วนลูปได้ · ตอนที่ 4 · แนว **ตลก** (กลัวจนขนฟู → ติดใจ)

**เรื่องย่อ.** Pumpkin นอนหลับกลางห้องนั่งเล่น (ห้องเดียวกับตอนที่ 2) หุ่นยนต์ดูดฝุ่นกลม ๆ ไฟตาแดงกะพริบ
แล่นเข้ามาชนก้น *ปึ๊ก* Pumpkin สะดุ้งขนฟูเป็นลูกบอล (สภาพ puff ที่เคยใช้ตอนแรก) กระโดดขึ้นไปเกาะผ้าม่าน "WHAT is THAT?!"
Pip ยืนโต้คลื่นอยู่บนหลังหุ่นยนต์อย่างเท่ "Relax. It only eats crumbs."
หุ่นยนต์ดูดเศษแครกเกอร์เป็นทางมาจนถึงใต้ผ้าม่าน หาง Pumpkin ห้อยลงมาพอดี *ซู้ดดด* ดูดหางยืดยาว "I'm… not… a crumb!"
ผ้าม่านหลุด Pumpkin ร่วงตุ้บลงบนหลังหุ่นยนต์ หุ่นยนต์พาวิ่งวนรอบห้อง "Make it stop! Make it STOP!"
แต่แล้ว… มันสั่นเบา ๆ เหมือนเครื่องนวด ขนค่อย ๆ ยุบ ตาค่อย ๆ ปิด "…Oh. It vibrates." "This is… actually nice." Pip: "Told you."
หุ่นยนต์พาเขากลับไปจอดที่แท่นชาร์จ Pumpkin กลิ้งตกลงไปนอนตรงที่เดิมแบบเฟรมแรก หุ่นยนต์ถอยออกไป วนลูป

**มุก 3 จังหวะ:** สะดุ้งขนฟูขึ้นไปเกาะผ้าม่าน → หางโดนดูด แล้วร่วงลงไปขี่หุ่นยนต์วิ่งวน → จากกลัวสุดขีดกลายเป็นติดใจ หลับบนหุ่นยนต์

**ฮุก 2 วินาทีแรก:** แมวส้มหลับปุ๋ย มีไฟตาแดงกะพริบเลื่อนเข้ามาจากขอบจอพร้อมเสียงหึ่ง *วี่ๆๆ*
(คนดูรู้ทันทีว่ามีอะไรกำลังจะเกิด)

## การจัดฉากใน 2D (มุมเดียว หน้าตรง ใช้ห้องจากตอนที่ 2)

- ห้องนั่งเล่นหน้าตรง: หน้าต่างซ้ายมี **ผ้าม่าน** (ของใหม่) ห้อยข้างหน้าต่าง, อาร์มแชร์ขวา, พรมฟ้ากลางห้อง
- **แท่นชาร์จ** ของหุ่นยนต์อยู่มุมขวาล่างใต้อาร์มแชร์
- หุ่นยนต์ดูดฝุ่นเห็นจากด้านหน้าเฉียงบน: จานกลมแบน มีไฟตา LED สีแดง (ตอนดูดเป็นสีเขียว) แปรงหมุนด้านหน้า วิ่งซ้าย-ขวาบนพื้นในระนาบเดียว
- ตอนวิ่งวนรอบห้อง = ส่ายไปซ้ายสุดขวาสุด และย่อ/ขยายเล็กน้อยให้เหมือนวิ่งเข้าออกระยะ (ไม่ใช้ 3D)

## ของประกอบ

| ของ | ปู | เฉลย |
|---|---|---|
| ผ้าม่าน | ห้อยข้างหน้าต่างตั้งแต่ช็อตแรก | ที่เกาะตอนตกใจ แล้วราวหลุดพาร่วง |
| เศษแครกเกอร์ของ Pip | Pip แทะไปทำตกเป็นทาง | ทางพาหุ่นยนต์ไปดูดหาง Pumpkin |
| ไฟตาหุ่นยนต์ | แดง = น่ากลัว | เขียว = ดูด, ฟ้าอ่อน = โหมดนวด (ตอนติดใจ) |
| สภาพ puff (ขนฟู) | ตอนตกใจ | ค่อย ๆ ยุบตอนผ่อนคลาย |

## เสียง

- **เสียงพูด:** 7 ประโยค (Pumpkin 5, Pip 2)
- **เอฟเฟกต์:** หึ่งของหุ่นยนต์ (วนตลอดตอนอยู่ในเฟรม), ไฟกะพริบ *ปิ๊บ*, ชน *ปึ๊ก*, ขนฟู *ฟู่ว*, เล็บจิกผ้าม่าน *ครืด*, ดูดเศษ *ซู้ด*, ดูดหาง *ซู้ดดดดด* (เสียงไล่สูง), ราวม่านหลุด *แป๊ก*, ร่วง *ตุ้บ*, ล้อวิ่งเร็ว, เสียงสั่นนวด + แมวคราง, แท่นชาร์จ *ติ๊ง*
- **ดนตรี:** สายลับตกใจ (สะดุ้ง) → ตลกวิ่งไล่ (เร็ว) → เพลงสปาผ่อนคลาย (ช้า มาริมบา) → กลับมาเงียบ ๆ ตอนจอด
