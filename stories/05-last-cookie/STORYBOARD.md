# Pumpkin & Pip: The Last Cookie · คุกกี้ชิ้นสุดท้าย — Storyboard v1

**YouTube Shorts** แนวตั้ง 1080×1920 · **50 วินาที** · วนลูปได้ · ตอนที่ 3 · แนว **ตลกแอ็กชัน** (slapstick)

**เรื่องย่อ.** Pumpkin เห็นโหลคุกกี้บนหลังตู้เย็น ข้างในเหลือชิ้นสุดท้าย เขาพยายามเอาให้ได้สามรอบ
**แผน A:** กระโดดสุดแรง ไม่ถึง หน้าแปะประตูตู้เย็นแล้วไหลรูดลงมาเหมือนการ์ตูน
**แผน B:** ต่อหอคอยจากของในครัว (กล่อง → หม้อ → หนังสือตำราอาหาร → ถาดพาย) ปีนขึ้นไป หอโยกเยก Pip นั่งดูไปแทะแครกเกอร์ไป
ขึ้นไปถึงยอด เปิดฝาโหล… **Pip นั่งอยู่ในโหลแล้ว** กำลังกินคุกกี้ชิ้นนั้นอย่างสบายใจ "Took you long enough."
Pumpkin อ้าปากค้าง หอคอยพังครืน เขาร่วงลงมาตุ้บ ของในครัวหล่นทับทีละชิ้น ถาดพายหล่นครอบหัวเป็นหมวก
ปิดท้ายด้วย "…Plan C." แล้วกล้องกลับไปเฟรมแรก (Pumpkin มองโหลคุกกี้ น้ำลายไหล) วนลูป

**มุก 3 จังหวะ:** กระโดดแปะตู้เย็น (ตลกทันที) → หอคอยโยกเยก ลุ้นจะพังไหม → หักมุม: Pip ได้กินไปก่อนแล้ว + หอพัง + ถาดครอบหัว

**ฮุก 2 วินาทีแรก:** ซูมคุกกี้ชิ้นเดียวเปล่งประกายในโหลบนตู้เย็น (มีวิ้ง ๆ) แล้วตัดไปหน้า Pumpkin ตาโตเป็นประกาย น้ำลายไหล
"One… last… cookie." (อ่านออกโดยไม่ต้องเปิดเสียง)

## การจัดฉากใน 2D (มุมเดียว หน้าตรง)

- ห้องครัวมองหน้าตรง **ตู้เย็นสูงอยู่ขวา** (โหลคุกกี้บนหลังตู้เย็น) **เคาน์เตอร์อยู่ซ้าย** (ของที่จะเอามาต่อหอคอยวางอยู่)
- หอคอยตั้งอยู่ชิดข้างซ้ายของตู้เย็น ซ้อนขึ้นตรง ๆ ในระนาบเดียว ทุกอย่างเห็นจากด้านหน้า
- Pip: ช่วงแรกนั่งบนเคาน์เตอร์ดูอยู่ ระหว่างที่ Pumpkin ก้มหาของ Pip ไต่ท่อ/สายไฟหลังตู้เย็นขึ้นไป (เห็นหางแวบ ๆ เป็นเบาะแสให้คนดูช่างสังเกต) แล้วไปโผล่ในโหล
- ไม่มีตัวละครอยู่สองฝั่งกำแพง

## เสียง

- **เสียงพูด:** 7 ประโยค
- **เอฟเฟกต์:** *วิ้ง* คุกกี้, น้ำลายหยด, ก้นส่ายเตรียมกระโดด, กระโดด *ฟิ้ว*, *แปะ!* หน้าแปะตู้เย็น, ไหลรูด *เอี๊ยดดด* (ขนถูกับประตู), ตึ้ง ๆ ตอนวางของต่อหอ, หอโยก *เอี๊ยด ๆ*, ฝาโหลแก้ว *ติ๊ง*, Pip กัดคุกกี้ *กรอบ*, เงียบ, หอพัง *ครืน*, ของหล่นทับ *ตึง ตึง ตึง*, ถาดครอบหัว *แก๊ง*
- **ดนตรี:** เพลงซุกซนแบบสายลับย่อง ๆ (pizzicato) ตอนวางแผน เร่งขึ้นตอนปีนหอ เงียบกริบตอนเปิดฝาเจอ Pip แล้วกลองรัวตอนพัง
