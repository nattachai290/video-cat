# Pumpkin & Pip: The Space Coaster · รถไฟเหาะข้ามมิติ — Storyboard v1

**YouTube Shorts** แนวตั้ง 1080×1920 · **50 วินาที** · วนลูปได้ · ตอนที่ 9 · แนว **ผจญภัย ตลก ตื่นเต้น**
(โครงเรื่องจากผู้ใช้: ชุดฉลาม → ประตูมิติ → รถไฟเหาะมารับ → แรคคูนเทาถือไม้เบสบอล → ซิ่งในอวกาศ → ปีศาจยักษ์ระเบิดดาว → กระเด็นเข้ามิติ · ผมแต่งต่อจากตรงนั้น)

**ตัวละครใหม่: Dusty** แรคคูนสีเทา หน้ากากดำรอบตา หางลายวง ใส่หมวกพนักงานรถไฟสีกรมท่า ถือไม้เบสบอลพาดบ่าตลอดเวลา
พูดน้อย เสียงทุ้มแหบ ทำหน้าเบื่อโลกเหมือนทำงานนี้มาพันปีแล้ว (ตัวละครแต่งใหม่ ไม่อิงตัวละครจากที่อื่น)

**เรื่องย่อ.** Pumpkin ใส่ชุดฉลาม ฮู้ดมีครีบกับฟันรอบหน้า Pip ใส่ชุดฉลามจิ๋วนั่งบนหัว "Rawr."
กำแพงห้องนั่งเล่นบิดเป็นวังวน **ประตูมิติ**สีม่วงเปิด *ฟิ้ววว* ลมดูดเบาะปลิว รางรถไฟเหาะพุ่งออกมาวนเป็นห่วง
รถไฟเหาะคันเล็กเบรก *เอี๊ยด* จอดตรงหน้า Dusty เคาะไม้เบสบอลกับฝ่ามือ "All aboard. No refunds."
ทั้งคู่กระโดดขึ้นรถ ราวกั้นลง *แกร๊ก* Dusty ใช้ไม้เบสบอลตีคันโยก *ป๊อก!* รถพุ่งเข้าประตูมิติ →
**อวกาศ:** รางบิดเกลียวผ่านดวงดาว ตีลังกาเป็นห่วง ฮู้ดฉลามปลิว Pumpkin "WHEEE!" Pip หลับตาปี๋เกาะครีบฉลาม →
หลังดาวเคราะห์ **ปีศาจยักษ์**สีม่วงหลายตาโผล่ขึ้นมา ใหญ่กว่าจอ คำราม คว้าดาวดวงหนึ่งบีบ… *ตูมมม!* ดาวระเบิดเป็นแสงวาบ →
ลูกไฟพุ่งมาหารถ Dusty ลุกขึ้นยืนบนรถ ตั้งท่าตี *ป๊อก!* ตีลูกไฟกลับไปเข้าปากปีศาจ ปีศาจสำลักควันเป็นวง "Home run."
แต่คลื่นระเบิดตามมาถึง รถหลุดราง หมุนติ้วเข้าประตูมิติอีกบาน →
**มิติสลับขนาด:** ทั้งคู่ตกลงมาในห้องนั่งเล่นที่ทุกอย่างสลับกัน Pumpkin ตัวจิ๋ว Pip ตัวยักษ์ Pip ก้มลงมามอง ยิ้มเจ้าเล่ห์
Pumpkin ตัวจิ๋ว (เสียงเล็กแหลม): "…Rawr?" Pip ยักษ์: "Well, well, well." →
รถไฟเหาะพุ่งทะลุเข้ามาช้อนทั้งคู่ไปทันที Dusty: "Wrong stop." →
ประตูมิติในห้องนั่งเล่นปกติ รถไฟเหาะโยนทั้งคู่ลงอาร์มแชร์ ขนาดกลับมาเหมือนเดิม มึนหัว Dusty แตะหมวกลา รถหายเข้าประตู ประตูหดเป็นจุด *ป๊อก*
Pumpkin จัดฮู้ดฉลามให้ตรง Pip กลับขึ้นไปนั่งบนหัว "Rawr." = เฟรมแรก วนลูป

**มุก 3 จังหวะ:** รถไฟเหาะข้ามมิติมารับ (แรคคูนพนักงานเบื่อโลก) → ปีศาจระเบิดดาว Dusty ตีลูกไฟโฮมรัน → ตกมิติสลับขนาด แมวจิ๋ว หนูยักษ์ แล้วโดนช้อนกลับบ้าน

**ฮุก 2 วินาทีแรก:** ภาพใกล้แมวส้มในฮู้ดฉลาม มีหนูชุดฉลามจิ๋วนั่งบนหัว ทำท่า "Rawr" ใส่กล้อง (อ่านออกโดยไม่ต้องเปิดเสียง)

## การจัดฉากใน 2D

- **ห้องนั่งเล่นเดิม** (ต้นเรื่องกับท้ายเรื่อง) ประตูมิติเปิดบนกำแพงระหว่างหน้าต่างกับอาร์มแชร์
- **รถไฟเหาะ:** รถคันเดียว ทรงกลมมน สีแดงเหลือง มองจากด้านข้าง มีที่นั่งสองแถว: Dusty แถวหน้า, Pumpkin กับ Pip แถวหลัง (เห็นแค่ครึ่งตัวบน)
- **อวกาศ:** พื้นหลังม่วงเข้มไล่น้ำเงิน ดาวระยิบ ดาวเคราะห์ลายวง รางเหาะสีเหลืองวิ่งซ้าย→ขวา กล้องตามรถ
- **ปีศาจ:** ก้อนม่วงยักษ์หลายตา มีเขาเล็ก ๆ แขนสองข้าง ปากกว้างฟันซี่ ๆ ตัวใหญ่จนล้นจอ (วาดใหม่ ไม่อิงตัวละครจากที่อื่น)
- **มิติสลับขนาด:** ห้องเดิมแต่ Pip วาดด้วยขนาดใหญ่มาก (u×4) และ Pumpkin วาดเล็ก (u×0.4) ใช้ rig เดิมได้เลย
- ตัวละครหน้าตรงหรือ 3/4 เป็นหลัก มุมข้างใช้ตามกฎใหม่

## เสียง

- **เสียงพูด:** 6 ประโยค (Pumpkin 3, Dusty 3, Pip 1 รวม "Rawr" สองครั้ง) Dusty ใช้เสียงผู้ชายทุ้มแหบ (Piper en_GB northern male เป็นต้นแบบ) Pumpkin ตอนตัวจิ๋วเร่งเสียงให้แหลม
- **เอฟเฟกต์:** ประตูมิติหมุน *วู้ม*, ลมดูด, รางพุ่ง *แกร๊ก ๆ*, เบรก *เอี๊ยด*, ไม้เบสบอลเคาะ, ราวกั้น *แกร๊ก*, ตีคันโยก *ป๊อก*, วาร์ป *ฟิ้ว*, รถเหาะวิ่งราง *ครืดดด*, ตีลังกา, ปีศาจคำราม *โฮกกก*, ดาวระเบิด *ตูมมม*, ไม้เบสบอลตี *ป๊อก!* ลูกไฟ, ปีศาจสำลัก, คลื่นระเบิด, หมุนติ้ว, ตก *ตุ้บ*, เงาทาบ, รถพุ่งทะลุ, ประตูหด *ป๊อก*
