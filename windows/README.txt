Snackatoon on Windows (NVIDIA)

1) Double-click 1-setup.bat           (once; if it asks, close the window and run it again)
2) Double-click 2-make-chapter.bat    (every time: pick the chapter, it records voices, mixes and renders)

The video appears in the chapter folder: out\video.mp4  (the folder opens by itself at the end)
If anything fails: screenshot the window and send it to Claude.
