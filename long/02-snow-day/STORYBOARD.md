# Pumpkin & Pip: Snow Day — Storyboard v3

**ความยาว:** 3:20 นาที (เนื้อเรื่อง 3:00 + End Screen 0:20)  
**รูปแบบ:** 16:9 · 1920×1080  
**แนว:** Comedy · Snow Adventure · Physical Comedy · Warm Ending

## Creative Direction

เป้าหมายคือทำให้คนดูรู้สึกว่าในทุก ๆ 2–4 วินาที มีอะไรเกิดขึ้นให้ติดตาม ไม่ว่าจะเป็นมุก สีหน้า การเคลื่อนไหว หรือเหตุการณ์ที่คาดไม่ถึง

หลักการ:
- เปิดด้วยภาพที่สะดุดตา ไม่เริ่มด้วยภาพนิ่งนาน ๆ
- ใช้ Reaction Shot เพื่อสร้างมุก
- ทุกมุกต้องมี Setup → Surprise → Reaction
- เพิ่มความวุ่นวายทีละระดับ
- ใช้ภาพและเสียงประกอบช่วยเล่าเรื่อง ไม่พึ่งบทพูด
- หลีกเลี่ยงการใช้ภาพซ้ำหรือการเคลื่อนไหววนซ้ำโดยไม่มีเหตุการณ์ใหม่

# PRODUCTION RULES

## Animation Rhythm
- หลีกเลี่ยงภาพนิ่งเกิน 2 วินาที ยกเว้นจังหวะที่ตั้งใจใช้สร้างความตลกหรืออารมณ์
- เปลี่ยนมุมกล้องหรือท่าทางเมื่อเปลี่ยน Beat
- Reaction Shot ต้องชัดและอ่านออก
- ใช้การเร่งและชะลอความเร็วเพื่อเพิ่มความตลก
- ไม่ใช้การซูมเข้าออกแทนการสร้างเหตุการณ์ใหม่

## Visual Continuity
- Pumpkin ต้องใช้หมวกและผ้าพันคอแบบเดิมตลอด
- Pip ต้องคงผ้าพันคอสีเขียว
- ประตูบ้านอยู่ด้านซ้าย เนินอยู่ด้านขวา
- ทุกฉากไล่ล่าเคลื่อนที่จากขวาไปซ้าย
- ลูกหิมะต้องโตตามการกลิ้งอย่างต่อเนื่อง
- ตัวละครต้องมีขนาดและสัดส่วนคงที่

## Audience Retention Check
- 0–3 วิ: มีภาพสะดุดตาและเหตุการณ์ทันที
- 3–15 วิ: แนะนำบุคลิก Pumpkin/Pip ผ่านมุก
- 15–60 วิ: สงครามปาหิมะเพิ่มระดับความวุ่นวาย
- 60–90 วิ: เปลี่ยนกิจกรรมและเปิดมุกใหม่
- 90–120 วิ: มีคะแนนตลกและจุดเริ่มต้นของปัญหา
- 120–156 วิ: ช่วงไคลแมกซ์ ต้องเร่งความสนุกต่อเนื่อง
- 156–180 วิ: เฉลยมุกและจบด้วยอารมณ์อบอุ่น

## Final Checklist
- [ ] ไม่มีช่วงที่ตัวละครยืนนิ่งโดยไม่มีเหตุผล
- [ ] ทุกฉากมี Setup, Action และ Reaction
- [ ] มุกเข้าใจได้แม้ปิดเสียง
- [ ] ไม่มีการใช้ภาพเดิมซ้ำเพื่อยืดเวลา
- [ ] ทิศทางการเคลื่อนที่และฉากหลังต่อเนื่อง
- [ ] เสียงช่วยเน้นมุก ไม่กลบเสียงตัวละคร
- [ ] ไคลแมกซ์มีความเร็วและความอลังการมากที่สุด
- [ ] ตอนจบอบอุ่นและไม่ลากยาว
- [ ] End Screen เริ่มที่ 180 วินาทีและจบที่ 200 วินาที
